# AXI4-Lite Test Cases

This directory contains directed and randomized SystemVerilog test cases for AXI4-Lite protocol verification.

## Test Scenarios

- AXI4-Lite basic test
- AXI4-Lite read test
- AXI4-Lite write test
- AXI4-Lite write-read test
- AXI4-Lite slave error read test
- AXI4-Lite slave error write test
- AXI4-Lite write strobe test
- AXI4-Lite write strobe random test
- AXI4-Lite WSTRB0 test
- AXI4-Lite WSTRB1 test
- AXI4-Lite WSTRB2 test
- AXI4-Lite WSTRB3 test
